# НЕ ГАДАЙ — ЛЕТИ

Готовый статический мобильный тревел-оракул от **Tatakomotako**. Никакого сервера, базы данных или платных API не нужно.

## Что внутри

- 72 авторские карты: состояние, желание, сценарий, действие, стоп-сигнал, джокер.
- Джокеры действительно редкие: 6% в «Карте дня» и небольшой шанс бонусной карты в «Удиви меня».
- «Карта дня» — случайная личная карта, которая фиксируется на устройстве до следующего календарного дня.
- «Помощь с отпуском» — 7 сценариев раскладов.
- Выбор между двумя вариантами без автоматического «победителя».
- Расклад для пары.
- «Удиви меня».
- Подсказки направлений по тегам расклада.
- Сохранённые карты в браузере (`localStorage`).
- Кнопка поделиться.
- Генерация вертикальной PNG-карточки для сторис прямо в браузере.
- PWA: сайт можно добавить на главный экран телефона; есть PNG-иконки для Android/iOS, базовые файлы доступны офлайн, а обновления не застревают в старом кэше.

## Как запустить на GitHub Pages

1. Создай новый публичный репозиторий, например `ne-gaday-leti`.
2. Загрузи **все файлы из архива прямо в корень репозитория**. `index.html` должен лежать в корне, а не во вложенной папке.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`, затем `Save`.
6. Через GitHub Pages появится публичная ссылка на сайт.

## Где менять контакты

В `index.html` найди:

```html
https://instagram.com/tatakomotako
```

и подпись `@tatakomotako`, если захочешь заменить контакт или вести на Telegram.

## Где менять карты

Все карты лежат в начале `app.js` в массиве `cards`.

Типы:
- `state` — состояние
- `desire` — желание
- `scenario` — сценарий
- `action` — действие
- `warning` — стоп-сигнал
- `joker` — редкая карта

У каждой карты есть `tags`: по ним блок «Куда посмотреть» подбирает направления.

## Важное про блок направлений

Он специально не учитывает цены, сезонность, визовые/въездные правила и доступность перелётов. Это игровой ориентир, а не актуальный подбор тура. Финальный CTA ведёт к турагенту.

## Структура

- `index.html` — интерфейс
- `styles.css` — дизайн
- `app.js` — 72 карты, расклады и вся логика
- `manifest.webmanifest` — установка как приложение
- `service-worker.js` — офлайн-кэш
- `icon.svg` — иконка

## Стиль

Палитра: молочный + бордо + песочный + чёрный. Чтобы поменять цвета, измени переменные в начале `styles.css` (`:root`).
